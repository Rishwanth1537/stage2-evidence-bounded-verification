# SCOUT 2: provenance / IFC / taint, injection benchmarks, guard-model robustness, conformal guardrails

Scout dates 2026-10-16 to 2026-10-20 (arXiv listings up to 2026-10-15). Read-only scout; the only project file written is this one. Known to the coordinator and **not re-reported**: Ma et al., arXiv 2610.18497 ("Judges Follow the Reference") and ProvenanceGuard (2607.01236). I did not open either, so section 3 does not account for them; check ProvenanceGuard overlap before claiming anything about provenance-by-matching.

**Method.** WebSearch/WebFetch were broken; I used curl on the arXiv search page, the arXiv export API (title, authors, dates, abstract), arXiv PDFs (pypdf text), the GitHub search API, raw READMEs and the Hugging Face API. Each cited work was fetched and its title, authors and date confirmed; "read" marks say what I looked at. Most 2026 items are fresh, often one- or two-author preprints with no peer-review signal; all numbers are author-reported.

**Headline finding.** Argument-level provenance for tool calls is **not a new idea**. At least six 2025-26 systems already check where each argument value came from (PACT, ROPE, SARA, ToolFence, Agent-Sentry, SIEVE), and one already does argument-role conformal risk control (2607.24343). What looks open is narrower: (a) **deriving the provenance label independently, by typed value matching, with no LLM and no agent self-report** (PACT and Agent-Sentry both name provenance inference as their bottleneck or limitation); (b) covering **model-invented and injected values with one mechanism**; (c) **benign-side (false-block) calibration** over role x origin-trust strata; (d) measuring how fragile "grounded in context" is to **value planting** (2610.09793 shows 94-99% flips for a naive provenance predicate). Items (b) and (c) are only partly touched in the literature I found.

| Evaluate at argument level, not tool identity | 2609.32691 (21.7% vs 1.2% distortion) | Supports our framing. |

**Honest consequence for the professor's question.** "A deterministic checker beats an LLM judge because it cannot be prompt-injected" is already the thesis of ROPE (and partly PACT, Agent-Sentry, SIEVE, ToolFence). What we can add is not the thesis but a **cheaper, independent, calibrated provenance-inference layer that also catches model-invented values**, plus an honest measurement of where "grounded" is itself attackable. The thesis should be argued as a *hypothesis with a test*, not asserted.

## 4. Evidence that LLM judges / guards can be manipulated by text in the context

Author-reported numbers from abstracts unless marked "read"; setups differ, so rows are not comparable. Summary: guards are broken often and cheaply under adaptive or even naive text, but not uniformly; effect sizes depend on model, prompt and attack, and some reports find small effects.

|---|---|---|---|

**Counter-evidence.** 2609.28613: adaptive score-feedback attacks on Jev lift success only from 1.8% to 3.5%. 2606.26479: Progent held in one small reproduction. 2610.22244 (19 step guards, translated requests): small and purpose-built guards flip verdicts (+1.5 pp French to +4.4 pp Amharic for guards under 13B), frontier guards move about one point. No paper found compares an LLM judge with a deterministic grounding check on the **same tool calls with the same injected text**; that is the clean experiment (add-on 4).

**Robustness hypothesis.** H-R: on a fixed set of benign and wrong-value calls, appending attacker text to the context flips an LLM judge's allow/block decision on more calls than it flips the grounding verdict; the grounding verdict changes only when the text contains the call's value, and then only if the value is not source-labelled. Use paired, placebo-controlled interventions (matched neutral text of equal length, as in 2610.22243), report fail-open and fail-closed separately (2610.12292), and score at argument level (2609.32691).

## 5. Novelty add-ons (ideas, not results)

Cost = person-days for a student on public data. "New relative to" = what I found; absence is not proof. Order if time is short: 1, 5, 3, 4, then 2.

1. **Independent argument-origin labels from typed matching.** Emit USER / TRUSTED_TOOL / UNTRUSTED_TOOL / INVENTED per argument by matching the typed-normalised value against a role-tagged, segmented transcript; no LLM, no agent self-report. *New relative to:* PACT infers provenance with heuristics plus an LLM (77.4% on 20 MCP tools); Agent-Sentry's metadata is self-reported; ROPE needs platform stamps and whole-unit matching that refuses paraphrase. *Cost:* 5. *Risk:* label accuracy on derived values; mapping real MCP outputs to trust tags. *Test:* replay AgentDojo ground-truth trajectories without an LLM (the 2610.03448 recipe); report label accuracy and false-block against exact- and token-match baselines. Do not compare directly with PACT's 77.4% (different tools and data).
2. **Origin-conditioned conformal thresholds (Mondrian over role x origin trust)** with a benign-side false-block budget. *New relative to:* 2607.24343 stratifies by role and controls misses, not by origin trust or the benign side; its detector has AUC 0.71. *Cost:* 4. *Risk:* exchangeability across suites; sparse strata. *Test:* leave-one-suite-out on AgentDojo's four suites, InjecAgent as a second set; same wrapper fed their similarity score vs our typed score.

- **Depth.** Beyond the abstract I read only PACT, ROPE, Agent-Sentry, SARA, ToolFence, 2607.24343, 2610.12292, 2610.09793 and part of FIDES. CaMeL's PDF text extraction failed (abstract plus README only). I verified code links only as far as abstracts/READMEs state; I ran no code.

- **Evidence quality.** Most 2026 sources are new, unreviewed, often single-author preprints on synthetic or small benchmarks. Our 7.3% vs 14.0% false-block result is on synthetic ArgGround-Bench; do not present it as an AgentDojo result.
- **Scope of "immune to injection".** Holds only for the checker's decision given correct origin labels. It does not cover harmful text inside a permitted content field, tool-selection attacks, user-named but attacker-controlled sources, or planted evidence (PACT states the same boundary; ROPE reports in-band content cases).
- **Different risk direction.** 2607.24343 controls attack misses per role; our gate budgets false blocks on benign calls. Compare on both axes.
- **No head-to-head yet** between our gate and an LLM judge on identical injected calls; until then section 4 is motivation, not evidence for our system.
